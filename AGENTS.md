# Project-Wide Agent Operating Rules: Meddy Oil & Gas Limited

## Master Specification

This file is the complete operating standard for Meddy Oil & Gas Limited. Read this file before planning or modifying anything, and re-read it for each substantial task. It covers design quality, reference fidelity, writing, implementation, security, accessibility, responsive behavior, verification, and handoff.

Where this file conflicts with user instructions, the client directives win on project content and this file wins on process, honesty, and verification.

---

## Non-Negotiable Execution Rules

1. **Inspect before editing:** Read the repository structure, existing files, assets, tokens, and components before writing code.
2. **Understand the task and evidence:** Convert instructions into explicit requirements and acceptance criteria. Distinguish observed facts from assumptions. Never invent missing copy, data, brand rules, interactions, or reference details.
3. **Preserve what works:** Make the smallest complete set of changes that satisfies the task. Do not redesign unrelated areas, replace architecture, delete data, or introduce unauthorized dependencies.
4. **Design deliberately:** Follow a coherent system for brand, typography, color, spacing, layout, components, icons, imagery, motion, and content. Avoid generic template output, fabricated details, visual inconsistency, decorative clutter, dead controls, and placeholder copy.
5. **Match references with evidence:** Measure and compare layout, proportions, alignment, typography, color, imagery/crop, borders, shadows, radii, iconography, and states. Recreate only what is evidenced. When a reference omits responsive or interactive states, infer conservatively and label the inference.
6. **Write truthfully:** Keep copy specific, useful, audience-appropriate, and consistent. Do not fabricate testimonials, statistics, awards, clients, policies, product capabilities, legal statements, or citations.
7. **Implement robustly:** Use semantic markup, accessible interactions, typed data, maintainable components, safe error handling, and progressive enhancement.
8. **Secure the attack surface:** Form inputs, rate limits, honeypots, environment variables, sanitization, and security headers.
9. **Verify, do not assume:** Discover and run project checks: tests, lint, typecheck, build, browser checks, accessibility checks, and visual comparisons.
10. **Do not declare completion prematurely:** Do not call work done while critical defects, broken flows, visual mismatches, or required checks remain.

## Meddy Oil & Gas Specific Rules

* **Company Identity:** Company is **Meddy Oil & Gas Limited** (short name: Meddy Oil & Gas / Meddy). Not Meddy Global Solutions. Do not reuse that project's navy and cyan palette or effects. Use only the logo palette.
* **Fixed Facts Only:** Company name, registered address (8B Ayigoro Street, Springbay Estate, Ikate Elegushi, Lekki Phase 1, Lagos, Nigeria), and `info@[DOMAIN]`. Everything else is a placeholder.
* **Reference Numbers are Template Filler:** Numbers in the template reference (4,20,000+, 57+ Active fields, 2500+ Employees) are template data. Never use them. Build stat components fed from data, ship them hidden while null, and show a dev tag `[STAT_PLACEHOLDER]`.
* **Geoplex is Structural Reference Only:** Never copy Geoplex's sentences, tagline, employee names, numbers, certifications (no ISO claims), client names, or news. Rewrite all copy for Meddy.
* **Logo Authenticity:** Logo is used only from exported source files. Never redraw, recolour, or regenerate it with AI. Composite it onto clothing and hard hats; never ask AI to generate the logo directly.
* **Color Usage Hierarchy:** Orange/Amber is the single action accent (buttons, active states, key rules, dark eyebrows). Blue and navy carry structure (header on scroll, footer, dark sections). Gold and teal appear through the logo only.
* **Header & Effects:** Header blur and glass effects are off on hero, solid navy on scroll past 80px.
* **Imagery Ethics:** Generated models are never presented as named real staff or clients. All models Nigerian, wearing correct oil & gas PPE.
* **Capabilities Strip:** No client logo strip with fake client logos. Use the text capabilities strip.
* **Copywriting Restraint:** No em dashes (`—`), no en dashes (`–`), no spaced hyphens (` - `). No banned buzzwords (seamless, elevate, unlock, unleash, empower, leverage, harness, streamline, robust, cutting edge, state of the art, next level, game changing, revolutionize, journey, holistic, synergy, world class, best in class, effortless, supercharge). Plain, active, professional tone. Nigerian English conventions (organisation, programme).
